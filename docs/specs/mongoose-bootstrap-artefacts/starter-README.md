# mongoose-hosted-fluxtion

**Demonstrates:** a Fluxtion graph hosted inside a Mongoose server (file feed → processor → file sink) with the admin web console, performance monitoring.

A Mongoose server, generated by the [Fluxtion project starter](https://fluxtion-playground.dev/start).

## Build & run

```bash
./check-fluxtion-key.sh    # verify your free Fluxtion API key first
./run-server.sh
# or:
./mvnw package && java -jar target/mongoose-hosted-fluxtion-1.0.0-SNAPSHOT.jar
```

Requires **JDK 21+**. The fat-jar manifest carries `Add-Opens` for agrona,
so `java -jar` needs no flags; running **MongooseMain** from IntelliJ uses the included
run configuration (which sets the same flags).

Web admin console: **http://127.0.0.1:8181**.

## What's here

- `config/server-config.yml` — the deployment descriptor (feeds, sinks, processor, services).
- `MyProcessor` — an `ObjectEventHandlerNode` that sees every broadcast event.
- `MongooseMain` — boots the server from the descriptor.
- `data/input.txt` — sample CSV rows (symbol,price,volume) the file feed reads on boot.

- `run-server.sh` — build-if-needed + run.
- `ServerSmokeTest` — boots the server in-process via `MongooseTestHarness`.

Default wiring: a file feed (`data/input.txt`) → `MyProcessor` → a file sink
(`data/output.txt`), with performance monitoring and the web console on.
