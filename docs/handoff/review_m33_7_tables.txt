2. FINDINGS
================================================================================
F1 (LOW-MEDIUM, fix before archiving this pair) — the Reports PANEL prints the rowWhen legend from
  the SectionSpec; the PDF prints it from TableData. For a record-less source with a refused
  rowWhen, TableData.rowWhen is null so the PDF is correctly silent — but ReportsPanel:319 tests
  `s.rowWhen() != null` and prints "‹label› — rows where ‹rule›" under a table that has no
  highlights. That is the exact trap D-I8 exists to prevent (an emphasis label claiming a rule that
  never ran), and it makes the report's acceptance-3 sentence ("assembled record-less tables have
  no printed rule") true of the PDF only. One-line fix: gate the panel's legend on
  `a.table().rowWhen() != null` — the same source the PDF uses.

F2 (paperwork, fix before archiving) — the report cites commits faa53c3 / 8715bbb / 7b88cae; after
  the rebase onto concurrent main the delivered commits are 800080f / b0d6b23 / db9c9db. The
  brief/report pair is the audit trail; SHAs that resolve to nothing defeat its purpose. Update the
  report's DELIVERED section (this review's diffs were read from the post-rebase SHAs).

F3 (nit, accepted) — the PDF path runs the scalar line through PdfDoc.clip, so a very long line
  (a wide filter description) can render truncated on the page while the panel shows it in full.
  The HANDED string is identical — acceptance 6 as tested holds — but "the same words on screen and
  in the PDF" has this one width-bound exception. Not worth machinery; recorded so nobody reads the
  claim as absolute.

F4 (note) — CoverageService.node() gives the echo's neverLogged entries two new keys (status,
  reason) that the old ActionExecutor entries did not carry. Additive and harmless to a
  forward-tolerant reader; named here because the echo is agent-facing surface.

F5 (note, spec'd behaviour) — the flat-store encoding cannot distinguish "a scalar string that is
  valid JSON text" from "an encoded structure": such a string parses into structure on reload and
  the call's value changes type across a restart. No real verb parameter has that shape today;
  D-T1's encoding accepts this ambiguity implicitly. Recorded so a future odd bug report has its
  cause named.
