6 · THE TRANSFERABLE LESSONS, WHICH ARE NOT ABOUT THIS CODE
================================================================================

1. FAILED WORKAROUNDS ARE NOT CONFIRMATION. When three attempts to work around a limitation all
   fail "for exactly the reasons expected", that is evidence the model of the problem is wrong, not
   evidence that the limitation is real. This cost a false upstream ask and a fabricated blocker.

2. AN INSTRUMENT BUILT TO STOP BIAS WILL STILL CARRY IT. The scorer's whole purpose was to stop
   comparisons flattering their author. It shipped with five more ways to do exactly that, all found
   by someone else executing against it. Adversarial execution is not optional for instruments.

3. FIXING A STATEMENT IS NOT FIXING AN ARGUMENT. I corrected a claim in the blog and left the
   paragraph that depended on it standing 200 lines later, directly contradicting the correction.

4. A CORRECTION THAT LIVES ONLY IN GIT HISTORY IS NOT A CORRECTION. Applied by both sides here: a
   reviewer appended a REVISED section to their own file after the follow-up caught them approving a
   line whose arithmetic mixed two configurations.
