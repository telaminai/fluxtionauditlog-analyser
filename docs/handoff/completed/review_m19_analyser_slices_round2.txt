2. ENTRY `297c4c1` — ATOMIC ENDPOINT PUBLICATION — ACCEPTED
================================================================================

Challenged as asked. The publication is correct in the details that decide whether the race is really
closed:

  · the pending file is created in the SAME parent as the target, which is what makes ATOMIC_MOVE
    possible at all — a temp in the system temp dir would silently degrade to copy-then-replace;
  · owner-only permissions are applied as a CREATION attribute
    (`PosixFilePermissions.asFileAttribute`), not set afterwards, so there is no window where the
    token file is world-readable;
  · `UnsupportedOperationException` falls back to a plain temp file (non-POSIX hosts), and
    `AtomicMoveNotSupportedException` falls back to REPLACE_EXISTING;
  · `finally { Files.deleteIfExists(pending) }` cleans the sibling on every path, including the throw.

Bounded-retry check: the bench's tolerance is inside `Analyser.wait`, whose loop is governed by the
pre-existing `deadline`; catching OSError/JSONDecodeError/KeyError/TypeError makes a malformed read
"not ready yet" WITHOUT extending the deadline, so a server that never becomes valid still fails by
step rather than hanging. That was the risk in the entry's own question, and it is not present.

Note (not a finding): on the non-POSIX fallback the temp file is created without the explicit
permission attribute. That path only triggers where POSIX permissions are unsupported, where the file
inherits directory ACLs instead; worth knowing, not worth changing.

3. ENTRY `389d331` — MAVEN-RESOURCE GRAPHML DISCOVERY — ACCEPTED

This closes F1 of my own discovery review, and it is fixed in the narrowest correct way: the resources
directory is appended to `graphRoots` ONLY — never to `sourceRoots` — and is guarded by
`Files.isDirectory`. Because `NewProjectDiscovery.apply` admits source roots exclusively from
`offer.sourceRoots()`, the extra root cannot be selected or persisted as a source root even if a user
confirms every box. That is exactly the "changes only what is offered" boundary the entry claims.
