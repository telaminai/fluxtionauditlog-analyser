3. CLAUDE DESKTOP / MCPB CONTRACT (M42.5)
================================================================================

Verifier: the independent M42 spec-review session.
Date verified: 2026-08-27.

The contract was read at these first-party sources:

- https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop
- https://claude.com/docs/connectors/building/mcpb

Finding: an MCPB needs a portable local entry point. This analyser's bridge is intentionally a
per-machine resolved JBang launcher or Java-and-jar vector; a bundle that re-discovers it would
duplicate the launch-resolution contract. M42 therefore ships the explicit Generic MCP configuration
fallback, does not write Claude Desktop's private configuration, and does not claim a bundled Desktop
extension. The design records the same sources and decision in
`docs/specs/completed/spec-mcp-client-install.md` under "Claude Desktop".
