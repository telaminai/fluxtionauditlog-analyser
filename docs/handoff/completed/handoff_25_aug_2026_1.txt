  1  `graph(Path)` ON THE SPI. Per spec §B:
         Optional<SourceGraph> graph(Path source) throws IOException;   // default: empty
         record SourceGraph(List<Node> nodes, List<Edge> edges, Provenance provenance)
         enum Provenance { DECLARED, INFERRED }
     · DEFAULT METHOD returning empty — Capabilities' lesson: this is a published surface since
       1.5.0 and every existing reader must keep compiling.
     · Provenance rides the RETURNED GRAPH, not the adapter (spec review F4): availability is per
       SOURCE, not per adapter — one Temporal estate has a registry export where another has none,
       so a fixed graphSupport() on the adapter would be wrong for half its users.
     · The graph is handed over in the CORE's vocabulary (D-A4): {id, label, className, kind} and
       {id, source, target} — the existing ProcessorTopology shape, already engine-neutral. An
       adapter maps its concepts onto NODE/EVENT/EVENT_HANDLER/EXPORT_SERVICE or declines a kind.

  2  RECONCILIATION with open {graphml} — the question M35 answered in a different key.
     THE RULE, and it is M35.3's asymmetry applied one level out:
         a graph the USER/AGENT opened is INTENT and wins;
         a graph the ADAPTER supplied is AUTOMATIC and yields.
     So: an adapter-supplied graph loads when nothing else is open; opening a graphml REPLACES it
     and says so; and the view states WHICH IT IS — D-A2's declared-or-inferred rule is not
     satisfied by loading the right graph, only by saying which one it loaded and where it came
     from. Reuse M35's machinery: judgeOpenedGraph() already states the pairing, and §E's
     `provenance` already carries "where did this come from" for the LOG — the graph needs the
     same courtesy.

  3  M34.2's first half if time allows: coverage must know DECLARED from INFERRED. The spike's §4
     finding is the acceptance test — __start__/__end__ counted as uncovered, so a structural flag
     or an adapter that does not emit pseudo-nodes. Coverage's value depends entirely on "declared"
     meaning "things that were supposed to run".
