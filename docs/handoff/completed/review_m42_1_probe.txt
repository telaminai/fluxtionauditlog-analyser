================================================================================
3. FINDINGS
================================================================================
F1 (minor) — VERIFIED has a narrow TOCTOU the ownership check cannot close alone. The probe checks
   pid, then launches; the bridge RE-READS the endpoint file per call (McpBridge.toolsCall). If
   another instance overwrites the well-known file in that window, the bridge reaches the OTHER
   analyser and the probe reports VERIFIED for this one. The window is milliseconds and requires a
   concurrent second instance, but the cheap tightening exists: after a successful context call,
   re-read the endpoint file and downgrade to OTHER_INSTANCE if the pid is no longer ours. Two
   lines; makes the VERIFIED claim airtight rather than very-probably-true. Recommend for M42.2.

F2 (minor) — LAUNCH_FAILED and PROTOCOL_FAILED are the only statuses without a test, and the
   -32022 leg of the era fallback is untested (only -32601, via the "legacy" helper). All three are
   cheap: a nonexistent executable; a helper emitting garbage; a helper answering discover with
   -32022. Worth adding before M42.2 builds UI wording on those statuses.

F3 (nit) — McpTools.READ_ONLY now has TWO stacked javadoc comments; only the second attaches, the
   original ("Verbs that never mutate the app…") dangles. Merge into one comment next touch.

F4 (note) — stderr is captured and then DISCARDED on every path, including failures. The in-code
   comment plans "the redacted tail for diagnostics" in a later UI; hold that plan — a
   LAUNCH_FAILED/PROTOCOL_FAILED with no child diagnostic sends the user to a terminal to
   reproduce what the probe already saw.

F5 (note) — the 5s per-exchange timeout meets a cold JBang launcher (first run, --fresh, JDK
   fetch) that can legitimately take longer to first byte; the process STARTS, so it reports
   PROTOCOL_FAILED "did not reply in time" rather than anything suggesting slowness. When M42.2
   words these statuses, give the timeout case its own honest wording or a longer first-line
   allowance.
