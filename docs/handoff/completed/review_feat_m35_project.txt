     agent never reaches the REST socket — the app simply does not finish starting. This is M35.7's
     species one step earlier: not in the load path, in the STARTUP path. Out of scope here, but it
     is the reason an isolated-home drive needs a seeded config, and it will bite the M19 onboarding
     bundle, whose whole premise is an agent starting a fresh install.

     whole project context. Doc drift, one sentence.
