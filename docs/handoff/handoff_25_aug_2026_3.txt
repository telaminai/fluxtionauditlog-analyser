  O-S2 → **replace only the RECORDS pane**, not the whole main area. The tabs ARE the product's

         app should learn its shape before using it.
  O-S1 → **bundle a demo SET, not a demo log — corrected before any code was written.**
         The first answer here was "bundle sample.yml". That was wrong, and checking it is what
         showed why: NO graphml in the tree matches sample.yml (0 of its 17 logged nodes appear in
         any of the three). A demo with no topology cannot show coverage, step-through, the dispatch
         order or source navigation — half of what the four sections claim — so it would have been
         exactly the "buttons that lie on first contact" failure D-S2 exists to prevent.
         The matched set already exists, generated by examples/fixture-generator, and is rule-1 clean
         (com.acme.demo throughout):
           demo-quote-audit.yaml          10 rec · 5/5 nodes in the graph   the walkthrough
           demo-quote-audit-traced.yaml   10 rec · 6/6 · TRACED             the only log where
                                                                            "did not run" is PROOF
                                                                            rather than inference
           demo-quote-series.yaml        726 rec · 302 KB                   enough data to chart
           demo-quote-processor.graphml   20 nodes                          5 logged of 20, so
                                                                            COVERAGE HAS A REAL
                                                                            ANSWER — the headline
                                                                            capability, demonstrable
           com/acme/demo/**.java          Nodes/Events/QuoteControl         source navigation from a
                                                                            node actually resolves
         Cost: ~330 KB in a 1.8 MB jar. Worth it — the alternative is a demo that cannot demonstrate.
         All of it moves to src/main/resources; none of it is in the shipped jar today.
         _Owner's prompt: "for the demo multiple logs and graphml is useful as well?" and "some code
         would make it more useful". Both right, and stronger than "useful": without the graph the
         coverage claim is undemonstrable, and without the source the topology is a picture you
         cannot click into._
