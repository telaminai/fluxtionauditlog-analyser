# M48.11 — the full chain, exercised end to end. It PASSES.

The gate a reviewer set after refuting UP-FLX-47:

```
FluxtionSpringConfig.logLevel → generated processor → real audit log
    → shipped reader → explicit dialect → ExpectationScorer
```

Every link now runs, and the comparison it was blocked on **passes**.

## What the block actually was

Round 57 reported it could not run a figure-by-figure comparison because the Spring route exposed no
audit configuration. **That was false.** Adding one bean to the resolver's own output is the whole fix:

```xml
<bean class="com.telamin.fluxtion.builder.extern.spring.FluxtionSpringConfig">
    <property name="logLevel" value="INFO"/>
</bean>
```

The resolver emits it on `--audit INFO`. Without the flag its output is **byte-identical to the
previously committed file**, verified after the change.

| link | evidence |
|---|---|
| config → processor | **17** `eventLogger` references in the generated source (was 0) |
| processor → log | **18** records from the scoring scenario |
| log → shipped reader | `YamlAuditReader` parses **18** records |
| reader → scorer | **12** scored events, 27 figures |

## Two harness defects fixed to get here

**The log was not in the analyser's own record format.** `Main` joined records with `\n`, so the
shipped reader parsed the whole file as ONE record — the defect
[`round-49/FORMAT-NOTE.md`](../round-49/FORMAT-NOTE.md) recorded and deferred. The harness now writes
the `---` document separator. **This affected the new log too**, so the deferral had been quietly
accumulating cost.

**The historical reference is preserved, and a derivative made.**
`round-49/expected.txt` is **unchanged and still authoritative**. `round-49/expected.conforming.txt`
is a derived copy containing **only records**, with its provenance in a sidecar,
`expected.conforming.PROVENANCE.md`: source path, both sha256 digests, record count, and the exact
transform — *insert `---`; alter nothing else*.

**The first version of this derivative put that provenance in the log as `#` comment lines, and a
reviewer found the reader absorbing them into record 1 as metadata.** A file created to be
format-conforming was neither conforming nor honest about itself. The rule this leaves:
**a derived evidence file contains only evidence; anything said about it belongs beside it.**
