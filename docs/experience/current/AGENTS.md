# Working in this project

**Read [`CLAUDE.md`](CLAUDE.md). It is the single source; this file is a pointer.**

`AGENTS.md` used to be a second copy of the same guidance and drifted: it described the Spring XML route
as the only way to add a node (wrong for any project whose `fluxtion-maven-plugin` goal is `scan`), and
it stated an audit-log rule that `CLAUDE.md` corrects. Eight independent agents in one measured round
reported the contradiction, several noting that many harnesses load `AGENTS.md` **by default** and would
therefore follow the wrong document.

Two files describing one thing is how that happens. There is now one file.
