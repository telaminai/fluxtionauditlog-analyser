#                                provider, which needs no key, is the exception, not the default.

#                                mongoose-dynamic-spring keep the key check out of that block but say the runtime
#                                load needs a subscribed key, "verify with ./check-fluxtion-key.sh".
#   cmd  <id>: root .cmd files the template ships besides mvnw.cmd (which every template ships); a template with no
