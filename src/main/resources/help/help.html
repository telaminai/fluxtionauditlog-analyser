If you are offline

  • An audit log is the record a Fluxtion EventProcessor writes: one record per event it handled, with an entry from each node that logged. A node that logged nothing may still have run.
  • Open a log with Audit log ▸ Open log…, or drop it on the window. The toolbar's Ask drafts a question about the selected records for the assistant; nothing is sent until you press Send.
  • Settings are under Project ▸ Settings…; how the assistant works is the Assistant: … ▾ control at the top of the assistant panel. No profile is local-only: with an assistant chosen, what you ask and the evidence it reads go to its model provider.
  • Release notes are under Help ▸ Release notes.
